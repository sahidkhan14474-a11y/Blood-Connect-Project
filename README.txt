BLOODCONNECT - BEGINNER FRIENDLY PROJECT

Is project mein sirf HTML aur CSS use hui hai.
JavaScript use nahi ki gayi hai.

FILES:
- index.html          = Home page
- donor-guide.html    = Donor guide
- myths.html          = Myths vs facts
- process.html        = Donation process
- blood-groups.html   = Blood groups
- find-help.html      = Official resources
- join.html           = Donor interest form and Contact Us
- css/style.css       = Website ka design aur effects

RUN KARNE KA TARIKA:
1. ZIP file ko Extract karo.
2. VS Code mein BloodConnect_Beginner folder open karo.
3. index.html par right click karo.
4. Open with Live Server select karo.
   (Live Server extension install honi chahiye.)

IMPORTANT:
- Donor form abhi demo form hai. Data kahin save ya send nahi hota.
- Email IDs aur toll-free number sample placeholders hain.
  Publish karne se pehle apne verified contact details lagao.
- Blood donation se judi eligibility aur medical advice ke liye
  hamesha trained medical staff ki guidance follow karo.

CODE STYLE:
HTML aur CSS beginner level par rakhe gaye hain.
Comments Hinglish mein likhe gaye hain taaki samajhna easy ho.
